理解代码时，先读[冻结八字段方案、预算与判读规则](docs/I11_OBJECTIVE_ALIGNMENT.md)，再读[候选与选择器](proposals/context_mixture.py)、[损失与预测白名单](proposals/objective_alignment.py)、[训练入口](tools/run_i11_objective.py)。正常基函数冻结，961参数选择器根据合法上下文给五个正常预测候选加权，所得节点证据同时用于检测汇总和条件根因排名；它不加载TimeRCD，也不是C04s双头结构。

# I09：从受污染观测中学习选择正常因果上下文

本分支独立于I08。I08是使用正常孪生的特权机制审计；本分支的推理输入只有observed、valid、正常DAG。正常孪生只可作为独立来源训练的loss目标。当前实际是否启动以项目根docs/STATUS.md为准；代码存在不等于实验完成。

## 为什么做这个实验

I08同32来源系统中，仅替换拟合上下文使关系AP50.773%→70.915%，而固定原方差后为58.749%。说明上下文同时影响正常均值和预测不确定性。我们现在检验：不提供答案，能否从上下文本身辨别更可信的正常关系。仅使NLL下降不算检测成功。

## Research Insight Card

| 字段 | 内容 |
|---|---|
| Problem | 已知正常DAG、未知系数/噪声、参考可能含故障的离线TSAD/RCA；主要来源关系AP、正常FPR和条件Top1，短/长测量保持性。 |
| Evidence | I08 CO−OO关系AP+20.143pp、32/32提升；空图CO约50%、错图约54%，真图70.915%。这些是oracle上界，不是现实模型结果。 |
| Failure Mechanism | 用全部受污染上下文拟合会把异常关系吸收为正常，还会抬高预测方差；查询与训练上下文隔离仍不能排除上下文自身有故障。 |
| Key Insight | 正常关系不应只由单个拟合决定。先在受保护的不同上下文上产生候选，再从上下文统计学习其可信度，保留混合不确定性。 |
| Novel Mechanism | 冻结正常神经基函数，分别推断五组局部系数/方差；共享小网络输出候选权重，混合正常密度和同均值三倍方差备择密度，得到节点Bayes-factor式证据。选择器不接收查询响应或候选位置编号。不是新Bayes/mixture算法声明。 |
| Closest Prior Work | ALPaCA的冻结表示/贝叶斯线性条件化、Robust Neural Processes的上下文过拟合/方差问题、其BNP基础代码中的多函数混合。本文借鉴成熟接口；没有复现完整NP或bootstrap算法。RobustNP全文17页已读，原作者新loss仓库未找到；BNP原作者四个核心文件固定阅读，不能冒称RobustNP源码。 |
| Falsifiable Prediction | 固定终点后真图选择器应优于其均匀混合初始状态和全部上下文；错图若同样改善，需把收益解释为通用稳健选择。隐藏显式父统计若无损，删除“选择器必须用这些统计”的claim。若NLL降而AP/FPR差，不扩大。 |

## 实现流程

1. 正常神经基函数固定为C04l的normal_only_s348。所有九run使用同一权重；348/349/350只控制选择器初始化和训练次序，避免基函数变化混进优化种子。
2. T=1024、评估t≥320、8个保护块、gap32，清除通过lag回流的拟合行。允许父同刻和0–8历史，自身仅1–32过去。离线可读取保护区外的未来上下文；这不是在线方法。
3. 五个候选：全部可用上下文，以及[32,280)、[280,528)、[528,776)、[776,1024)四个分区与保护掩码的交集。至少64拟合行，否则mask。全部候选共享原观测fold中位数/MAD和特征标准化。全上下文候选必须数值等价I06。
4. 每候选三次Student-t IRLS，ν=4、单位ridge，得到正常均值和预测方差。仍可吸收受污染自身历史，本轮只改上下文估计。
5. 共享12→32→16→1 Tanh选择器，共961参数，末层零初始化，初始精确均匀混合。输入12项：log样本数、log特征维数、log噪声、平均IRLS权、设计能量、逆精度trace、自身系数范数、截距、父数量、父系数范数、父拟合分量方差、父拟合分量与响应协方差。统计只来自各候选拟合行；没有候选ID、query值、标签、根因或真实参数。
6. 正常密度是五个Gaussian的加权混合；备择保持各均值、将各方差乘3。节点证据=log p备择−log p正常，再沿通道LSE汇总。单候选时精确等于旧残差能量；不把混合均值当作单Gaussian近似。
7. 只训练选择器，最小化正常配对响应在混合正常密度下的NLL。Adam lr=.001，梯度norm1，单case一次update，一遍512case固定终点；不按验证选best。孪生不进入components或selector接口，只进入训练loss。

## 三臂与公平性

| 臂 | 图/统计 | 目的 |
|---|---|---|
| true_all | 正常真图、全部12统计 | 候选主方法 |
| true_hidden_parent | 同真图，但选择器最后4项父统计置0 | 同参数/同拟合/同曝光，检验显式父统计的额外作用；其余统计仍可能间接包含父信息，不叫无因果模型 |
| wrong_all | 固定保持入/出度的错图、全部统计 | 检验正确边身份；可能有环，仍无自身边，单独标明干预图 |

每臂各348/349/350三个优化种子，基础权重348一致。相同种子训练次序和初始化一致。每run保留全上下文与均匀混合基线。错图保持度，特征维数/参数/FLOPs阶数相同；缓存因数值不同不能共享，实际重算单列。隐藏父统计并未减少模型参数或因果拟合计算。

## 数据与固定预算

训练64个新底层系统，C8/12/16/20各16；linear/tanh/sin是熟悉机制，不说完全机制未见。新seed空间348009000000+C×10000+i。每系统正常/关系交换两分支各一对，再plain/smooth；关系起点256/384/512/640平衡，完整单通道类别多重集逐通道SHA匹配。25%共同前缀有轻微污染，不假设参考干净。训练仅正常关系与关系交换；单点/128点故障作为未在本轮训练的新故障样式检查。

每run **7,340,032原观测曝光＋7,340,032正常响应标量监督**，九run共66,060,288＋66,060,288。这不是全套foundation训练，仅961参数的上下文选择器有限学习。全部输入/权重/缓存/代码SHA固定。

每run组件预计算512训练＋512验证＋64正常校准case=1088case，原输入15,597,568标量；九run共140,378,112冻结输入，另逐项记录特征行、Cholesky次数、查询节点数和缓存字节。与优化曝光不能混为同一计数。初始/终点完整评估，128/256步只用预定8验证系统画曲线，不作选择；输出所有seed与逐系统负例。预检另列，不算正式优化曝光。

固定512步或4小时先到停止；非有限/泄漏/哈希不符即停止本项目新调度，保留错误和已完成预算，不影响别人。不反传250M任何划分，不打开150M锁定，TimeRCD不测RCA。

## 判读门槛

G0：全上下文与旧模型等价<1e-8、初始均匀<1e-12、候选顺序置换等价、受保护query不影响selector上下文统计、自身当前/未来不入预测特征、梯度仅selector、所有SHA通过。正常预测拟合允许目标闭式计算，全局权重在目标固定。

预登记主比较为关系AP的true_all-final−uniform、true_all-final−full、true_all-final−wrong_all-final，共3项系统配对Holm；每系统先平均三优化种子和背景。局部支持至少平均+0.02、系统bootstrap区间下界>0且Holm<.05；正常FPR相对full不能增加>0.005。门槛用于是否扩大此原型，未通过仍报告局部信息，不宣布方向永久失败。短/长AP下降>0.02或条件Top1下降>0.05时，不作为通用检测器扩大，需改受保护组合。NLL单独下降不通过。

- `tools/preflight_i09.py`：G0审计。

# I08：把拟合上下文污染与预测输入污染分开

这是**仅来源的oracle机制审计，不是可部署方法**。在已完成I06的同32系统、同异常查询上做成组干预，保留原始响应不变。3套冻结normal_only基函数；不加载TimeRCD，不读取250M数据，不做训练。

## 为什么做

I06中，真图直接因果能量能检测短故障，但简单送入TimeRCD后损失信号。128点测量故障的真图条件Top1为48.958%，低于空图66.927%；关系故障检测约50%。我们要区分：上下文拟合已把故障当正常，还是错误的自身/父观测把正常预测带偏。不能用真图整体差就否定因果信息。

## 七个固定对照

O指实际观测，C指同系统、同随机轨迹、同背景但没有本轮后缀注入的正常孪生。孪生仍保留共同的前缀污染，**不是默认干净参考**。它只在本审计提供特权信息。

| 名称 | 拟合数据 | 查询预测特征 | 要分离的作用 |
|---|---|---|---|
| OO | 观测 | 观测 | 数值复现I06残差/方差 |
| CO | 孪生 | 观测 | 只修正上下文回归数据 |
| OC_own | 观测 | 自身过去用孪生，父观测不变 | 自身历史污染 |
| OC_parent | 观测 | 父当前/过去用孪生，自身不变 | 父测量错误污染 |
| OC_both | 观测 | 自身和父均用孪生 | 联合输入污染 |
| CC | 孪生 | 自身和父均用孪生 | 两者同时修复的特权对照 |
| OC_sham | 观测 | 把同幅修正移到错误时间 | 改动大小相同的错误修正控制 |

所有臂的原观测响应、fold观测median/MAD和观测特征标准化相同。CO只改变回归设计/响应，从而改变beta、噪声与leverage；不额外改变归一化。另报固定OO方差的残差能量，以区分均值修正和方差容忍度。sham为修正向量循环移512点，可能与长事件重叠，不能称完全作用在无异常区间。

三种图均做：真图、空图、节点置换错图。错图保持全局度数多重集，未保持每节点入度。仍用8fold、gap32、3轮nu4 IRLS、正常基函数、允许同刻父观测；自身当前/未来不进入查询预测特征。拟合允许保护区外的未来上下文，是离线闭式推断而非在线模型。

## 数据、G0和预算（运行前固定）

复用I06的32验证系统，每系统12个后缀故障视图（关系、1点、128点，正/负方向与plain/smooth），C8/12/16/20均衡。原4个正常视图、16系统校准预测复用，零额外正常GPU推理。它是对已见来源结果的后验解释，不冒称新盲测。未加入物理故障，不据此声称能区分AO/IO全部情形。

96任务=32系统×3套冻结权重，4A100＋6H100按显存余量调度。每进程4GiB、需≥5GiB空闲，不停止其他进程。固定上限2小时，任一数值错误停止本节点新任务，保留错误/已有记录；下一接续先阻止本项目两节点继续调度再独立revision修复。不得扩大当前预算追分。

- 训练曝光/优化更新/TimeRCD调用：全部0。
- 新增上下文拟合输入计数99,090,432；节点特征行863,944,704；Cholesky分解1,741,824；查询节点预测238,436,352。
- 原输入字节、已有缓存/权重SHA绑定；每任务OO残差和方差均与I06同点缓存核对，最大绝对误差<1e-8。
- 只有OO重新拟合以获取旧任务未保存的系数，旧TimeRCD与其余I06矩阵不重跑。
- 每节点预检2个case，额外计数单列；null、无自身当前/未来特征、保护区和冻结参数必须通过。正常视图的所有臂必须等于OO。
- 保存逐点分数与远程节点残差/方差、配置、源数据/代码/权重/输出SHA。代码另分支，不覆盖I06。

## 判读与后续训练资格

主比较预登记：真图CO−OO、OC_both−OO，各看AP和条件Top1，分三类故障，共12项系统配对比较、Holm12。按系统先平均3seed和2背景，bootstrap10000/seed348；同时保留mean差区间、升降系统和原始差，不以单个p值或全检测AUC>.85否定局部机制。own/parent、CC/sham、错图、固定方差及C/族/背景为解释性分解。

必须同时检查：改善是否比sham有方向性，正常null是否精确，是否只出现在一两个系统，是否把故障能量转移到别处。CO有局部支持优先研究可信上下文；OC_parent有局部支持优先研究观测误差模型；若仅CC有效，单独清洗或单独改拟合不足。oracle改善不证明已存在可学习的无特权解。后续训练必须另建来源训练池，比较等容量/曝光的原始、保护修正和假修正，固定3seed和预算终点；本阶段不自动展开大训练。

## Research Insight Card

| 字段 | 内容 |
|---|---|
| Problem | 已知正常拓扑的TSAD和条件RCA；长测量故障定位差、关系检测接近随机。指标AP、独立正常FPR、条件Top1及真根/子/其他节点残差。 |
| Evidence | I06真图能量短故障AP53.801%、拼接TimeRCD17.527%；长故障真图Top1低于空图17.969pp。真实失败与正信号共存，尚未唯一归因。 |
| Failure Mechanism | 候选一：异常污染上下文，正常估计吸收异常；候选二：错误测量作为自身/父输入，在正常预测中制造或抹去残差。 |
| Key Insight | 拟合时的错误和查询输入的错误应分开干预，否则不能知道该训练正常上下文还是观测误差修正。 |
| Novel Mechanism | 同异常响应、同归一化的上下文×特征oracle分解，含自身/父分解和错时修正。是诊断设计，不宣称新算法或已实现修复模型。 |
| Closest Prior Work | Chen–Liu1993联合异常与ARMA估计、后续tsoutliers；ALPaCA正常机制条件化、CIRCA父条件诊断；AO/IO和鲁棒修正均是已有思想。全文与后续作者核心源码已在主项目阅读记录固定。 |
| Falsifiable Prediction | 若坏父输入是真原因，只修父特征应在真图长测量故障降低伪子证据、提升定位，错误时间修正无相同收益；若只修上下文有效，改输入不足。若oracle也无可恢复信号，当前接口应停止。 |
| Minimal Experiment | 上述96任务、同32系统、3冻结权重、7臂×3图×两方差读出，0训练、2h。先G0，再逐系统判读，不能把oracle性能当通用模型成绩。 |

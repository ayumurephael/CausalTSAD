# I06：因果残差输入究竟提供了什么信息？

本分支是独立来源、冻结权重的机制诊断。它不训练，不宣称性能已提高，也不重跑已完成的 E1–E4。此前 E4 在 80 个开发系统上，原 multi AP 47.687%，加入真实图残差后 50.010%，但配对区间跨零、正常误报增加；这只是需要解释的线索。

## 固定实验

- 32 个新来源验证系统＋16 个来源校准系统，C=8/12/16/20 各组系统数相同，长度1024。线性/tanh/sin 是已研究的机制家族，只宣称底层系统独立。
- 每个验证系统有两个正常分支、两个完整单通道轨迹类别精确匹配的关系破坏分支、两个1点测量故障、两个128点测量故障。局部故障从512开始，正负3MAD；原关系四元组保持不变。每种都有 plain/smooth 两种背景，共16视图。校准只含两个正常分支的两种背景，共4视图。参考前缀可能污染。
- 3套已冻结正常基函数，种子348/349/350。使用各case自身的8折、32点保护区外上下文做IRLS潜参数估计；父通道同刻及0–8滞后、自身1–32滞后可用。闭式离线推断不是在线预测，也不是目标梯度训练。
- 因果残差按预测方差标准化，与原观测拼接。比较真图/空图/固定置换错图，真残差通道循环错配和时间循环移动；后两者不改变各通道的值集合，但分别改变配对或时间结构，不能把下降直接当作“因果关系证明”。错图保留全局度数分布，不保证逐节点度数不变。
- 等通道数对照为 `[x,x]`、`[x,0]`，另有原 `[x]`；与基函数种子无关的三项只运行一次。
- 两个输入范围分别从320和32开始；所有分数最终只评320–1024共同点。32以前无可用自身历史，不凭空补预测。范围控制同时改变上下文长度、位置和整段归一化，不能单凭差异把三者分开。
- 同一次TimeRCD前向比较原mean、max、温度1的log-mean-exp，以及只汇总原观测一半的mean。**这些都是TSAD读出，不输出TimeRCD根因排名。**因果模型自身另报真实事件窗口内的条件Top1/Top3/MRR。

## 计数、终点和判读

48系统×3权重=144任务。新输入共8,257,536观测标量，训练曝光0。计划因果重复前向74,317,824标量；TimeRCD重复输入478,679,040标量、20,736次前向。max/LSE复用同一次编码，不增加编码成本。技术预检单列，所有实际计数写入每任务回执。最长2小时，真实错误停止本节点本项目队列；不增加数据、步数或搜索窗口。

每种故障分别将同系统的两个正常视图和两个故障视图拼接算AP/ROC，再按独立系统配对分析；不同故障异常比例不同，不比较其裸AP来断言哪种机制更易学。正常FPR阈值固定由16个来源校准系统的分数99分位给出，分别按方法/背景/基函数种子校准，验证不调阈值。三种权重种子先在系统内平均，不冒称96独立系统。

主比较：原mean读出的真图对空图/错图、原输入、重复/零通道；分别报告关系破坏、短/长测量故障和背景，不把其中最好的一格当总体收益。预登记的真图对空/错图两项×三故障的六个配对检验作Holm校正，置信区间按32系统bootstrap。方向一致且区间排除零支持对应局部机制；区间跨零是证据不足，报告效应和负例，不自动否定有限训练资格。是否训练还要结合FPR、输入控制与机制可解释性，禁止只凭一个大平均值扩大。

完整验证数据、旧250M、锁定测试不读取；正常孪生、root、生成参数只在来源生成/评估审计使用，不进入预测函数。每份输入和输出都有SHA。先检查原生mean和32起始结果公共后缀数值等价、保护区和显存，再部署。每次前向完成后检查冻结参数未变。

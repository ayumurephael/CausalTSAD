## 已完成结果（2026-10-27）

32项已完成、42文件SHA核验。固定时间统计量权重，真图AP69.068%／条件Top1 64.583%，错图65.652%／55.382%；13系统AP反向变化。错图训练头换真图也有收益，新头真图训练带来的额外AP差中差仅0.740pp，定位额外差不稳定。类型读出去除正常类可将Top1从59.288%恢复到64.236%，但联合检测定位没有改善，尚未胜过无类型头参照。

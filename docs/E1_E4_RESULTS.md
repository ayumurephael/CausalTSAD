# 第一档E1–E4完整结果：上下文有帮助，因果输入尚未稳定超过TimeRCD



2026-10-26。**288/288任务、240/240目标任务的预定四指标全部完成；取回、SHA和旧基线等价核验通过。**本轮没有训练新模型，全局权重更新0次。原始结果、旧失败日志和历史模型均保留。

## 1. 先读这几句话

**最扎实的进展是修正正常上下文。**旧因果模型只用前256点估计正常关系；改为在待评分块之外取上下文后，AP从15.589%到23.677%，给定真实异常窗口的根因Top1从45.614%到58.333%。这说明旧上下文限制了这版模型，但不能断言它是全部失败的唯一原因。

**最值得保留、但还需反证的方向是“原观测＋因果残差”输入TimeRCD。**平均AP从47.687%到50.010%，VUS-PR从41.203%到44.743%；然而AP提升区间跨0，正常误报从0.784%升到1.837%。它没有稳定全面超过原检测器，更没有SOTA证据。

**主要增益集中在原生成机制。**机制留出轨的组合AP仅19.346%→19.453%；真图、空图、错图在这一轨非常接近。不能把原机制的好案例推广为已经解决关系故障，也不能把未显著的全局比较当成“因果一定没用”。下一步应保留正证据、用独立来源配对查清何时有用。

## 2. 测了什么，数字代表什么

这是已有共同80个多变量**开发系统**，原机制/机制留出各40，C=8/12/16/20各20。每系统的正常与含异常case独立推断。主评测后缀为t≥320：其中76个系统仍有有效异常（每轨38），4个无有效异常不填AP=0，但正常FPR仍计入80系统。16个独立来源系统的正常视图只负责固定各方法99%分位阈值。**目标正常孪生不用于拟合、选阈值或帮助异常case。**

三套已有因果权重seed348/349/350分别运行；先对同一系统的seed平均，再平均系统，不能把它当240个独立系统。E4使用自训练uni/multi，原输入及[x,x]不依赖因果seed，实际只计算一次。

AP衡量异常点的排序质量，不是准确率；VUS-PR综合时间容忍范围下的PR表现；正常FPR是纯正常case超过**来源固定阈值**的比例。条件Top1/Top3已经给了真实事件窗口，不包含自动检出成功率。TimeRCD按照用户要求完全不评RCA。表中所有成绩为百分数，FPR越低越好，其余越高越好；pp表示两个百分数之差。

E4从t=320开始把每种输入按TimeRCD原生规则重新标准化，并以至多5000点窗口前向。故本轮原multi AP47.687%应与本轮组合比较；旧“先输入全序列，再截取后缀”的48.457%不是相同输入上下文，不能直接相减。全部432多变量开发系统的45.927%又是另一范围，不能混成同一排行榜。

## 3. 实验怎样实现

**E1，换正常上下文。**把本case分8块，评分某块时仅用块外上下文，排除32点保护间隔，并额外删除任何自身/父历史特征引用了该块的拟合行。使用原神经基函数、ridge、3轮ν=4稳健重加权及查询相关的leverage方差。它可读块外未来，是离线方法；另设只读过去的8块扩展版本。不是利用当前标签重新训练模型。

**E2，补充周期和父历史。**从无标签整条观测的ACF峰估计自身周期P，增加P/2P历史；父输入另增加9–16和17–32点的两个衰减摘要。分别测试只加周期、只加父历史、同时增加，防止把自身季节建模误认为因果收益。无真实lag/coeff/noise输入。

**E3，改变同一残差的评分。**令q=r²/v，单点能量为0.5×((2/3)q−log3)，窗口为1/8/32/128。各窗的平均能量乘sqrt(W)，比较中心与尾随窗口。脚本原口径先跨通道LSE，再按整条case的median/MAD标化每个尺度，逐时取最大；文档另一口径先逐通道MAD，再跨尺度取最大。两者分别报告，不按真实标签选窗。定位取所选尺度的节点证据；不是另训RCA头。

**E4，把因果信息放到TimeRCD输入。**比较标准化预测残差→uni、估计去父驱动序列→uni、沿通道维拼接[x,r]→multi。原观测uni/multi、[x,x]、空图/错图残差共同控制。去父驱动是估计值，不是真实正常孪生；[x,r]是输入拼接，不是两个模型分数相加。新增通道还改变位置编码/上下文，因此真图胜错图也需要逐案例反证。

输入只含观测、valid与正常拓扑；父当前观测允许，自身当前/未来不直接成为正常预测特征。离线ACF、全case归一化和MAD会读整个case，包括查询统计，已披露；不能称为严格在线。250M任何划分均不反传，本轮不打开validation或locked。

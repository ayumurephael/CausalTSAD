# C04p：让因果创新读出学习短、长故障的取舍

| Research Insight Card | 内容 |
|---|---|
| Problem | 正常DAG已知的新系统，固定因果预测器的单点读出擅长短故障、16点读出擅长长故障。希望同时保住短事件AP/条件定位、改善长事件；不把读出改进冒充正常预测已解决。 |
| Evidence | 完整C04n：32独立源的duration<=4，point相对16平均AP+26.953pp，95%系统区间[21.896,31.645]，31/32上升，正常FPR只增加0.193pp。源长故障反过来下降。目标80系统总体AP14.36→15.59不稳定，原机制11.48→24.15、留出17.24→7.03；条件Top1 30.70→45.61。事实支持取舍，不支持单点通吃。 |
| Failure Mechanism | 固定平滑将短故障分数拖入恢复段；完全不平滑又无法积累弱的持续创新。训练源只含长事件时，很容易隐藏这个接口问题。 |
| Key Insight | 用事件注入时间监督读出，让同一正常机制证据按时间形状处理，而非在目标集按标签选一个窗口。 |
| Novel Mechanism | 冻结3个normal_only正常预测器；每节点用W1/4/16/64/256上的标准化残差均值、绝对均值、能量均值、预测方差均值（log压缩）作为20维输入，训练共享20→32→16→1小头。它输出检测证据/条件根因排名，不是已校准真实因果后验。未来foundation方法是否采用该固定窗口库另议，本轮是接口学习探针。 |
| Closest Prior Work | R8 AERCA全文/核心代码已读，区分外生注入与传播时间是先例；R21 BOCPD全文与固定镜像演示已读，事件持续时间推断是成熟思路；多尺度MLP本身不称新颖。R23 FANS全文31页及核心代码已读，强调正常模型误差会污染残差解释；这里不复制其每目标NF重训或GAM。 |
| Falsifiable Prediction | multiscale应比相同参数的current-only和固定混合控制，在新来源长事件有增益，短事件不靠牺牲大幅AP换取；若current-only同样好，只支持再校准/普通适配；若固定混合同样好，不支持学习按时间分配证据必要性。 |
| Minimal Experiment | 三臂×3个配对seed348/349/350，1217参数/臂。新源64train/16cal/32validation系统，每C8/12/16/20各16/4/8，索引i100..127，与旧诊断i0..7独立。每run64updates、7,340,032原观测曝光，共66,060,288。固定final64，不选best；阶段只评来源，不打开任何250M数组。 |

三臂均使用相同压缩point基础项`log(1+r²/v)-log3`，零初始化残差MLP。**这与旧Gaussian point在跨通道汇总后不等价**，因此单列该共同初始基线、原point和原W16。point臂把当前4维特征重复5次；fixed_mix臂把5个尺度平均后重复；multiscale保留20维。参数/线性层乘加相同（1217参数、每节点时间1168MAC），预处理与有效信息量不同，不能说完整FLOPs/有效容量完全相等。

损失为正/负时间点各半的检测BCE＋0.25根因CE，根因CE只对真实注入区间。训练输入8view=2normal＋6个按固定种子抽取的故障view，所有臂相同；背景plain/smooth交替，smooth沿用旧共享观察背景幅4MAD/周期.75T，**是合法观测干扰对照，不声称观测层精确满足原SCM**。参考前缀仍可能污染。1D标签保持直接注入时间，物理尾部不伪造effect；三新增影响标签null。

额外预算：正常预测器只算一次，可复用feature bank；112系统中cal只算两正常view，train/val各42view，两背景×3冻结seed，总349,569,024完整输入slots。头训练66,060,288原曝光另列；最终来源头评估355,074,048等价原slot应用，三个固定读出额外1,065,222,144 slot应用（不是额外骨干前向）。保存实际query/特征元素/时间/bytes和SHA。来源数据生成额外计数，所有目标更新为0。

G0：当前输入/未来隔离、相同初始化/每步特征SHA/原曝光、梯度只在头、骨干参数不变、初始精确等于共同压缩point。头FP32通道置换误差预定<=5e-6；旧float64骨干等价门槛不变。来源各臂按同系统和seed配对，3seed是完整流水线配对重复（冻结基函数本身也随seed不同），不是额外独立系统。

G2分别判读短/长与normal FPR，不用CE下降放行：若长事件相对point改善>=2pp且系统区间下界>0，保留长事件学习信号；是否允许目标迁移另需全体AP胜两学习控制、短事件相对point下降<=2pp、FPR恶化<=2pp。未达到完整门槛不能抹掉有证据的局部方向，但当前64步原型不无限追加步骤。4h技术期限先到停止，不停止他人任务。

所有来源重新独立；未新做25亿完整数组重合扫描，不冒称做过。主模型只用X/valid/正常G，真实参数/根只供源builder和训练目标；自身当前/未来不进正常预测，同刻父分支单列允许。当前只C>=8，不能宣称保持C1或达到最终foundation/SOTA；目标仍需未来冻结方案后检查。

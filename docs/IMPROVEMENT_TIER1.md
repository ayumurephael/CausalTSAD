# 第一档 E1–E4：冻结方法，检查上下文是否掩盖因果图收益

本阶段直接响应用户提供的《分析与改进.md》，不是继续增加 C04s 小头。独立分支 `diagnostic/improvement-tier1-v1`，旧 C04s、全部旧结果不改。四个诊断在同一不可变快照运行；后续训练 proposal 仍各建独立分支。

## 要检验的主张

前256点可能不能代表整个正常系统。若用不含当前预测块的多段上下文估计机制，真父图可能比空图/置换图提供更可靠的残差；再让检测器理解残差的时间形状，而不是只判断残差幅度。

这是假说，不把附件数值当已复现事实，也不把某批冻结方法失败当 DAG 信息上限证明。

## 冻结范围和信息

已有共同80个多变量development系统、两轨各40、C8/12/16/20，正常/异常各独立推断。原pilot选择不变；主比较t≥320。三套既有 normal_only 最终权重seed348/349/350全部固定。源16系统的2正常视图×plain/smooth用于每方法99%分位阈值；不从目标正常孪生校准异常case。没有训练、没有验证/锁定数组、没有 oracle 参数输入。

离线交叉拟合是本case潜参数估计，明确允许使用预测块之外的未来观测；不称在线方法，也不称完全没有目标估计。自身当前不作预测特征；父同刻允许。在线扩展窗口另列，只用当前块之前的历史，更新机制仍可能吸收持续故障。

## 防止将预测块通过历史特征放回拟合

每fold排除预测块、指定gap，并检查训练行自身全部1–32和P/2P滞后所引用的原始时刻，凡落入预测块都排除。gap0/16因此也不是允许响应泄漏的版本，实际上下文数量全部保存。E2长周期滞后会使可用上下文减少，逐fold保存；不能只报告名义K。

ACF范围8…min(1500,T/4)，取最高局部峰；无峰则不加周期，不能从标签选周期。P/2P历史尚不存在的时刻，用0加显式合法标志，绝不用未来补齐。ACF和global归一化控制是明确的全case无标签统计，不称对holdout完全独立的统计量。主E1 fold归一化只用其允许上下文。

保留原r²/v证据及预测leverage方差；没有把交叉拟合方差悄悄降成常数。长父历史使用两个归一化指数加权摘要，衰减不被单列标准化抵消。

## 指标、预算和终点

所有方法AP/ROC-AUC、来源阈值正常FPR；因果E1–E3给真实事件窗口的Top1/Top3/MRR，E4无RCA。预定主要条件补原四指标；完整逐点分数和SHA保留。系统为bootstrap单位，3种子先在系统内汇总；两轨、C、事件类型/长度、正常误报和所有下降系统都报告。多重主要比较用Holm校正，不按开发标签挑窗口/模型。

80目标＋16校准×3seed=288任务；r2修复后每任务最多32GiB（r1的8GiB上限导致拼接输入OOM，旧错误保留），最多4 A100＋6 H100并行，按输入token数估计所需显存并留2GiB余量分配。不停止他人。原始曝光、特征行数、每fold矩阵分解、TimeRCD实际/补齐输入和调用次数逐任务记录；所有优化曝光=0。推断12小时技术上限，固定矩阵跑完即止；任何新非有限值/哈希/泄漏错误停止本项目队列保留错误，独立revision修复，不续调超参。

主比较为xfit真图−prefix真图、xfit真图−空/错图、E2组合−xfit、E3center_case−xfit point、E3center_channel−center_case、E4真残差uni−原uni、E4[x,r]−[x,x]。AP提升3pp和区间为正是工程候选门槛，RCA/FPR分开报告；未达成不证明DAG无用，不机械阻止更局部机制的有限学习。

## Research Insight Cards

### I01：覆盖更完整、受污染可鲁棒的机制上下文（E1）
| 字段 | 内容 |
|---|---|
| Problem | 零样本已知DAG，正常漂移导致高FPR和低AP/条件Top1。 |
| Evidence | 旧迁移正常FPR21.71%、相位敏感；附件未独立复现的交叉拟合增益。 |
| Failure Mechanism | 初始短片段对后续系统外推失准；并非已确定唯一原因。 |
| Key Insight | 图的增量要在可覆盖正常状态的上下文下判断。 |
| Novel Mechanism | 替换潜参数推断上下文，保留冻结基函数与原不确定性；purged分块而非当前点回归自身。 |
| Closest Prior Work | ALPaCA的共享基函数/上下文回归；CIRCA的父条件异常检验；分块交叉拟合并非新算法。 |
| Falsifiable Prediction | 固定归一化和方差后仍改善；若只有global归一化有效，不归因拟合覆盖。 |
| Minimal Experiment | E1全部固定对照，正常/故障独立，图控制和在线分列。 |

## 资源恢复 r2

r1对 `[x,r]` 的显存预算不足，属于执行错误，尚不是方法效果。r2不改窗口、输入、参数、评分或实验矩阵；仅提高进程上限、按任务体量调度，并对已有完整记录核验任务、分数和残差缓存SHA后复用。最大5000×40输入单独预检，8/32GiB上限的同一小输入概率必须完全一致。未持久化的失败/被中止任务需重算，额外成本单列，不能声称所有失败前计算都被复用。保留原12小时截止，不以故障延长科学预算。

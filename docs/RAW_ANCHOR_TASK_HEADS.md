# C04s：保护原始检测证据，再区分检测与定位的读出

本版独立于C04p，旧代码/权重/结果不改。是冻结正常因果预测器的来源小头实验，不是完整foundation预训练。

| Research Insight Card | 内容 |
|---|---|
| Problem | 同一个因果正常预测器能否同时支持检测与定位？目标是来源AP、正常FPR和条件Top1，分短/长、原样/平滑背景、C和机制族。 |
| Evidence | C04p多尺度比同容量单点AP高0.600pp，但整体低于原始能量；其压缩基础经LSE等价于平均通道能量。C04n只改时间读出便提高目标条件定位，说明失败不必来自梯度冲突。旧C08/PCGrad仅修复部分问题。 |
| Failure Mechanism | 证据压缩可能稀释少数通道故障；另一个候选机制是同一通道logit同时承担绝对报警与相对根因排名，两个目标争用最终分数。两项均待实验，不假定必然成立。 |
| Key Insight | 先恢复原始读出精确初始化，再用同一冻结表示区分时间特征、监督和任务私有参数；避免把换初始检测器误称学习收益。 |
| Novel Mechanism | 原始Gaussian单点能量e不变，零初始化残差MLP修正e；检测沿用原temperature/bias和LSE，定位softmax通道分数。双头只把两个任务的MLP分开，正常表示仍共享。不是首次双头/多任务设计。 |
| Closest Prior Work | R11 PCGrad全文/作者核心代码已读，强调共享参数梯度冲突但不保证此处是主因；R22 ALPaCA全文/核心已读，沿用共享正常表示加前向闭式系统推断。成熟方法可用，此版先辨原因，不作novelty/SOTA声明。 |
| Falsifiable Prediction | 若压缩是重要问题，原能量锚点可恢复初始AP；若时间特征有用multi胜point/fixed_mix。若最终任务竞争，dual相对等容量shared2改善AP且保定位；若shared2同样好，只支持容量；若det-only也不胜joint，不支持当前根因损失伤害检测的解释。 |
| Minimal Experiment | 6臂×3seed348/349/350，复用C04p64train/16cal/32val的SHA缓存，每run64步、7,340,032等价原输入曝光，总132,120,576。0新骨干、0目标数组。固定final不选best；2h技术期限，不追加lr/步数追分。 |

六臂：`point_joint`当前特征、`fixed_mix_joint`固定尺度均值、`multi_joint`全部尺度、`multi_det`仅检测损失、`multi_shared2`两个MLP平均后共用检测/定位、`multi_dual`两个任务各自MLP。前三及det臂1217参数/每node-time1168MAC，后两2434参数/2336MAC；只能将shared2与dual称参数/MAC匹配，不把1217对2434的收益归为解耦。预处理特征相同，缓存读取与评分另计。

每MLP20→32→16→1，首MLP种子相同，第二MLP seed+1000。各输出层零初始化，所有臂初始检测和定位精确等于原始单点能量。Adam lr.001、64共同view计划、正负各半BCE＋.25根因CE；det-only去掉根因项。梯度裁剪每个MLP独立norm5，避免dual的根因梯度通过全局裁剪改变检测更新。两双MLP臂均执行两个网络，shared2也具有不同隐藏初始化。给定真实事件窗口的“条件排名”并不等于自动检出→定位。

源数据/冻结权重沿用已记录SHA，三seed不是新系统。来源训练每步只选8view，plain/smooth交替。所有臂旧normal预测、前缀污染和直接注入1D标签策略相同。物理传播尾部不伪造effect标签，三个新增影响标签保持null。

额外预算：0新正常骨干；18run来源最终头评估710,148,096等价原slot应用，三个固定基线2,130,444,288应用，非骨干前向。实际训练query node-time90,832,896另记。参数/MAC和每run时间/峰值显存、输入/特征/权重/代码SHA均保存。已探索来源验证不能冒称新盲测；原C04p最终来源数据虽曾用于比较，但没有按本版结果选配置。

G0先验证原能量zero误差0、任务私有梯度、同seed首MLP一致、无目标数据和有限梯度；实际初始化对缓存原基线要求<=1e-8。系统内平均三seed后系统bootstrap。局部资格为相关子任务AP或定位配对区间正向、对应FPR不过度恶化；不把小于2pp的稳定局部信号抹掉。完整目标迁移还需总体AP胜原能量，或明确验证独立定位头能保住强检测参照；CE下降不放行。

# C04j：正常关系估计是否过期？与稳健似然分开检验

## Problem
原始因果创新模型在32来源系统AP89.15%，迁移到80多变量生成开发系统却只有11.79%，同点集TimeRCD48.46%；纯正常case误报50.23%，原机制轨甚至82.43%。先区分正常预测失准与故障证据组合失准，再决定可训练方向，不能把这套原型当已经可用的检测器。

## Evidence
真实图仍比错图/空图平均AP高约2.5–2.7个百分点，但真图完整故障模式不优于相同预测器的局部模式。来源完整协方差vs通道分块差+0.437pp，95%CI[-0.082,1.131]；vs纯对角差-0.126pp，CI[-0.508,0.254]。现有样本没有可靠跨通道协方差必要性证据。以上为实测，背景/参数过期是待检验假说。

## Failure Mechanism
固定前256点推断出的正常关系可能无法解释很长序列上的正常季节性/背景变化；再把这些正常预测误差当故障证据，会持续误报。另一种解释是固定特征族不够表达正常动力学；即使换近历史也无效。第三种风险是更新上下文会把持续故障学成正常，必须保留反证。

## Key Insight
先只换“估计正常关系所依据的时间段”，保留同样256点、同样回归和故障头；它若降低正常误报而保留关系故障，才给进一步学习上下文选择的资格。普通滚动拟合是机制探针，不是最终基础模型创新。

## Novel Mechanism
一个固定诊断接口：每256个查询点重算一次自己的256点上下文；上下文末尾与首个查询之间保留64点隔离，正常预测仍仅自身过去/直接父当前及过去。每块时间基准局部重置，窗口/步长事先固定，不读目标标签选。前向闭式潜参数变化不等于目标SGD，也不能写成完全无适配。

## Closest Prior Work
完整阅读R21 Adams & MacKay2007（7页）：对不同run-length解释做前向预测与后验更新，默认分段i.i.d.且正常/故障不是它自动解决的语义。镜像代码147行已完整读，作者身份未证实；不是我们的BOCPD复现。这里先固定滚动历史，只检验时间失配，未实现Bayesian run-length混合。成熟滚动回归本身不主张novelty。

## Falsifiable Prediction
受控平滑正常观测背景下，滚动上下文若改善正常校准与AP；但同样精确边际匹配的持续关系故障AP/晚期证据不能被吸收。若正常误差仍很高，应优先解释特征/动力学不匹配；若只减少误报同时丢失持续故障，不能扩大该原型。

## Minimal Experiment
- 已有80来源系统只读16校准＋32验证，训练32个系统数组不开；与250M目标数组完全不反传。两种图：true_signature和empty_signature；3个既有冻结先验head。不训练、不挑head。
- 两种背景：原样；所有8视图同一逐通道平滑sin观测背景，幅度4×来源共同前缀MAD尺度、周期0.75T，固定系统种子/通道相位。这个人为合法观测背景不是物理故障或新effect标签；模型不接收其参数。逐完整通道的原matched quartet精确类别多重集再次校验。原标签、根因、物理/测量视图区分保留。
- 对照固定前缀Gaussian、近历史Gaussian、独立分支的固定前缀Student-t；不混淆改变历史和改变似然。fixed/plain证据复用旧缓存，不重算。
- 冻结目标诊断：仍是历史100系统中80多变量、同t>=320。比较新两接口的AP/AUC/条件真事件窗RCA、正常误差时间分层；不是锁定性能评测、不读取validation/locked。C1继续旧旁路，不新算。
- 源校准阈值只从相同16底层系统×两背景×两个正常case池取99%分位数，各方法各表示独立计算；不从目标正常孪生拟合。B0旧阈值池没有平滑背景，保留原值作为参照，不据此直接宣称严格同校准池FPR优势。主判读AP和正常模型误差，补报完整来源校准下FPR。
- 先来源反证，再决定是否有有限学习资格。目标冻结诊断仅解释已知失败，不因目标表现挑新参数或扩大训练。禁止只看正常NLL/CE。

# C04m：慢背景失败，是周期本身还是前缀没有覆盖正常变化？

| Research Insight Card字段 | 内容 |
|---|---|
| Problem | C04l在慢背景1.5T来源AP53.80%、正常FPR29.72%、条件Top1 13.54%，而.75T背景AP62.14%。先判别正常前缀覆盖不足是否相关，不提前换学习率续训。 |
| Evidence | 同32系统/三seed中NLL改善并未带来慢周期的可靠AP改善，定位反而下降。原滚动历史会吸收持续故障；简单重尾也没解决失配。覆盖不足是新假说，尚非事实。 |
| Failure Mechanism | 当前case前256点可能刚好位于背景波峰的窄范围，却被用于解释之后的大范围正常观测；固定岭回归/神经特征在未覆盖区域可能失准。另一解释是频率、正常机制或故障证据读出本身，而非覆盖。 |
| Key Insight | 相同全长幅度与故障、仅改变前缀相位的成组干预，可把“慢”与“前缀看过多少正常变化”分开。 |
| Novel Mechanism | 无新模型或学习。周期.75T/1.5T × 前缀中心为零交叉/极值；逐通道固定随机正负号、幅度4×未加背景前正常共同前缀MAD，不用标签选相位。固定源final的frozen_basis和normal_only，真图/空图、全部3seed。该相位实验是机制诊断，不是自适应前端。 |
| Closest Prior Work | R22 ALPaCA的条件特征与域外不确定性，尤其Appendix A的有界非线性/模型失配边界；R19模式似然以模型有效为前提。均已全文读，不把前缀覆盖/因果上下文称原创。 |
| Falsifiable Prediction | 同周期/幅度/底层系统内，窄覆盖前缀应有更大范围外比例、正常误差和FPR；若相位效应不稳定或控制覆盖后仍随周期变化，就削弱覆盖解释。真图/空图对照用于区分一般背景问题与图条件建模，不把相关性当因果证明。 |
| Minimal Experiment | 只读32来源验证系统，8视图×四个相位/周期条件；2模型臂×3seed×2图。标签/根因仅在模型调用后算AP/条件RCA。完整单通道类别多重集再次验证，旧labels/null字段不改，不读250M任何数组。 |

前缀中心固定127.5。对每通道以key种子产生s_i∈{-1,1}，b_i(t)=4 MAD_i s_i sin(2π(t−127.5)/(period·T)+φ)，φ为0或π/2；所有视图加同一个b，不输入φ/period/s_i。这是声明的正常观测偏置，不声称物理DAG在任意测量坐标下都静态不变，也不构造effect真值。

阈值沿用C04l独立16来源校准系统的两正常/两背景固定99%，不在新phase或source_validation重校准。按32底层系统配对、seed内聚合，报告四条件AP、正常FPR/白化误差、范围外占比、条件RCA和全部负例。只用结果决定是否开展有限的新机制模型，不自动因FPR降低放行。

## 当前最有用的结果

1. **源根因监督能学到定位，但不自动改善检测。**C08 v1的true-DAG+root目标M条件Top1=42.08%，local+root=38.75%；ID-M为60% vs50%，机制留出却24.17% vs27.5%。不是普遍图收益。原始detector没有可比RCA头，不能给它编一个根因分数。
2. **定位置信度不该自动提高异常分数。**原LSE读出包含`KL(U_C||softmax(node))`，因此即使总证据均值不变，仅根因分布更集中也会抬高异常。去掉此逐时刻项，M AP47.348%→47.931%、FPR0.3986%→0.3459%；源normal常量校正保持AP不变、错时序KL不能恢复，支持这是原型读出的具体问题。它只解释我们C08的退化。
3. **重新训练验证了读出修复，但还不是稳定超越。**mean读出AP47.914%；mean+PCGrad AP48.017%，原模型47.940%。相对原模型AP差95%CI[-.001474,.003824]，VUS差CI[-.001295,.004220]。PCGrad相对mean本身有小正信号，但正常FPR仍升，RCA Top1降至40.42%。不挑某seed宣布成功，也不自动加步。
4. **条件校准确实可学习。**C09源normal pinball条件=.097700、边际=.107113，条件约低8.8%；交换错条件恶化+.017013，边际对交换严格不变。条件信息改善正常分布预测，但目标M整体AP没超过B0，提示“机制预测/校准→故障判别”的转换仍未解决。
5. **测量污染不是当前已证实的普遍瓶颈。**C05冻结源隔离没有建立平均子误报的稳定上升：65个有子系统35升30降，区间跨0；超过源正常阈值的额外症状只在1系统/1seed出现。可研究特定故障，不应据此假设所有误定位都由坏父观测导致。

## 实际并行与下一步

C08 24组、C09 12组、C08b新9组均已完成，C05六模型和C08十二冻结机制审计也完成。C09+耦合审计曾同时4A100+5H100，C05+C08b同时4A100+4H100；不是只把任务排成串行。GPU可共享，但不抢停别人进程。

当前C03v2已在3A100+4H100实际优化，九组任务。其在独立`proposal/c03-learned-tail-context-v2`：沿C09合法输入增加过去条件/创新配对的共享学习摘要，对照no_context/learned_mean/learned_median×3seed。固定3遍normal密度+3遍观测/normal融合，总有效密度80,538,624、原观测融合80,538,624、额外normal融合80,538,624；原模型/teacher冻结、C1不变。前256点全部臂保留原分数，完整检测指标仍包含全部标签点集。源验证只交换历史摘要、保留当前条件不变，另做污染历史诊断。该实现是C03的一次可学习接口检验，不是完整潜后验或foundation全量预训。

先看独立源预测和错误上下文反证，再看固定开发性能/下降例，不根据目标标签加lr/轮数。若失败，区分摘要瓶颈、污染和检测读出；若通过，再针对具体原因设计配对训练与独立baseline，不照编号机械训练十套。新颖性建立在新机制与有效证据上，不能把采用CNP或PCGrad本身称novel。

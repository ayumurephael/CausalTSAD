# C04o：残差与父通道共同变化的证据

| Research Insight Card | 内容 |
|---|---|
| Problem | 已知正常DAG、但未知系数/lag的新系统中，边机制变化可能难以用单点残差能量识别。先在独立来源32系统检验检测AP、正常FPR和条件根因Top1；本阶段不做生成基准迁移。 |
| Evidence | C04l-T中边lag/系数变化的AP约2%；来源正常学习收益没有迁移。事实是检测失败，尚未证明是残差读出失灵。R8 AERCA全文/作者核心代码已读：将外生创新定位和下游症状区分，是直接先例。 |
| Failure Mechanism | 系数小变动会产生与父历史相关的有符号残差，平方后丢失此结构；但坏正常预测也会产生同样的相关，不能直接称因果识别。 |
| Key Insight | 保持正常预测器和残差完全一致，仅比较“残差能量”与“残差是否沿父特征子空间偏移”，检验图是否提供额外可用证据。 |
| Novel Mechanism | 固定W16，将系数扰动作为零均值Gaussian潜变量边缘化，比较D与D+tau²ZZ'。Z为父通道0–8lag特征，先以前256点回归掉自身历史；三tau²等权混合，另有同宽非父特征对照。所有头共享同一真图正常预测器；不是把错图正常预测差当收益。 |
| Closest Prior Work | R8 AERCA创新诊断、R22 ALPaCA的贝叶斯线性条件化、经典Gaussian随机效应边缘似然均是成熟先例。本实验没有新的传播模型或已证明novelty；B03完整学习核仍未完成。 |
| Falsifiable Prediction | 在边系数/lag源案例上真父头应超过能量和等宽非父头；若非父同样提高、正常FPR失控或只改善点故障，不支持特定父关系解释。 |
| Minimal Experiment | 32新源系统、42case/系统、3冻结normal_only seed。与C04n共享同一次前向的残差，0优化；本轮不读目标数组来评该头。源校准仍旧独立16系统两背景两正常。固定混合、固定终点，4h技术期限。 |

工作似然使用逐点预测方差的对角近似，忽略参数不确定性的完整时序相关；不冒称正确校准的贝叶斯后验。窗口开头按真实可用点数计算，不复制同一证据16次。根因先验1/C，节点无父时只保留能量模式；有父时能量/关系模式等权，避免度数直接变成更大先验。

G0：零残差零特征、直接dense公式与实现一致、合法normal mean无自身当前/未来，真/非父同列数、参数不变。G1：按独立系统/3seed聚合，报告全反例；边变化AP均值增益及95%系统bootstrap下界>0，并胜等宽非父，正常FPR恶化不超过2pp，则允许后续有限源训练；否则停止当前固定头，不据此否定整个图方向。统计阈值是本轮资格规则，不是SOTA标准。

# 已知正常图 TSAD + RCA：输入、对照与实施协议

状态：通用协议。B1、C01、C02、C03的具体已执行配置与结果以registry/research_status和各独立分支为准；下面未标已实施的设计仍是建议。具体预算、宽度、匹配阈值在启动前冻结。用户已允许独立baseline；2026-10-25又明确允许单列的同刻直接父通道输入。

## 1. 任务与数据

共同输入为 `X[T,C]`、合法点掩码、正常系统 `G=(V,E)`，边约定 `source,target`。输出为连续时间异常分数 `s[T]`、通道根因排名/概率，以及可选故障时间后验。模型不得接收 case_id 中的 normal/anomalous 字样、sample_id/seed、fault type、根因、正常孪生、注入窗口、payload、系数、噪声或异常后的图。

训练/测试真实 DAG 已获授权；主实验只用拓扑，真实正常 lag 是单列增强对照。对同一系统的正常与异常 case 使用完全相同正常 G。图的边顺序不得暗含滞后/强度排序。新加载器必须显式白名单构建 `model_inputs`，不能把整个 record 或 `attribute` 传给模型。

原 `benchmark_data.get_case()` **不返回 G**，且返回部分监督字段，不能直接当新模型输入字典。本轮保留原数据/代码，不静默改变旧 API；新实现应独立增加因果输入适配层，将预测输入、训练目标和审计信息分开。需要 lag 时只复制正常 `edge_lag`，不复制 `events.parameters.fault_lag`。

250M 基准按系统隔离：每轨开发 25M、验证 25M、锁定 75M，两轨共开发 50M、验证 50M、锁定 150M。每个系统有正常/异常两种观测，聚合时它们是同一个统计单元。开发用于方案诊断、验证用于冻结配置；锁定只在最终配置固定后评估。所有三部分数组都不参与梯度。机制留出不是“所有后来模型都从未见过该类机制”：每个新模型必须登记源训练的机制 exposure。

源训练来自原 2.5B 或另建种子/系统独立训练池。原记录的 normal_time_series 可作源正常机制监督，events/root 可作源 RCA 目标；源正常/异常观测分支的额外计算必须记录。原数据不能覆盖，新的训练源与基准做系统/seed/完整数组哈希去重。目标正常孪生只属于隔离评测/审计，不用来选择上下文、归一化或校准阈值。

## 2. 必须防住的条件输入泄漏

**2026-10-25明确授权扩展。**在单列的 contemporaneous-parent 分支，可读取正常DAG直接父通道的`t`时刻值；不能读取当前目标自身`t`或任何未来值来生成其预测分布。自身分支仍严格过去，逐通道归一化与单层父消息必须防止目标值绕路进入自己的预测。C01/C03历史记录的严格过去协议不改写。RCA/异常分类后验可读取已经产生的当前创新；它不是目标盲的条件均值预测器，两者不能混称。

**分数表示审计。**原概率口径保留。C01补充审计发现float32概率饱和会损失AP排序；共同raw-logit对照已完成。VUS/阈值采样指标还依赖分数表示，不能把其全部变化归因于舍入。后续学习试验须预先固定共同表示，并给原模型同样表示的对照；禁止混比旧probability/newlogit，也不按目标标签选择表示。源正常1%阈值在各表示中分别冻结，目标侧不重新拟合。


- 因果预测器预测 `x_i,t` 时，输入只来自协议指定的自身过去和父过去。预测当前点所用 patch 不能含当前点/未来点；也不能从包含它们的全注意力 hidden state 取得信息。源/目标一致。
- 严格父分支的非父值不变性要覆盖所有上游操作：归一化、动态权重生成器、图聚合、上下文编码、batch 统计和特征缓存。不能只检查最终 attention mask。
- 主任务是离线 TSAD，可以有固定无标签前向上下文，但必须与查询区域隔离，R 不保证干净；不宣称在线。真正在线版本仅使用过去，独立报告。
- source 正常机制损失在正常源分支上计算；不能要求带故障父值的上下文去预测干净孪生，同时还把这叫正常条件密度学习，除非明确采用 C05 的潜状态模型。
- 同时检查 C1、无父节点、常量通道、空图、合法长度、channel permutation。空父集合需要明确定义的仅自身历史路径，不能出现全掩码 NaN。

## 4. TSAD 指标与不确定性

- 主指标 VUS-PR，辅以 AP；同时保留原实现的 `Affiliation-F`、`F1_T`、`Standard-F1`、`VUS-PR` 四项。原计算函数与周期规则绑定代码 SHA，不静默改指标公式。
- 原四指标在带事件 case 上计算；正常 case 的 PR/F1 等若无正例则记 undefined，不伪造 0 或 1。正常误报单列；不能把正常/异常 case 拼成时间连续序列计算 VUS。
- 不同模型的原始 NLL、创新、概率不共用数值 0.5 阈值。FPR/检测延迟/端到端 RCA 需先用**独立源正常验证集**选择共同目标误报水平并冻结阈值；主水平1%的源分位数校准已在B1/C01及C08执行，不能写成尚未实施。完整误报曲线另报；C08的源校准范围为M，C1原分数保持且两者用同base-M阈值，范围须单列。
- 按独立底层系统配对，报告每轨、C、机制族、故障类型、持续时间、强度和负例；总体用系统宏平均，同时列有效样本数。不要只给平均最高的一行。
- 3 个优化种子不是 3 个独立数据系统。数据系统 cluster bootstrap 给性能差区间，优化种子单列；同系统 normal/anomalous 和多个事件不作伪独立样本。多重比较探索性结果标明，不以单一 p 值决定方向生死。

## 5. RCA 定义与评测

**根因是实际故障起始通道，不是图中入度为 0 的节点。**边系数/滞后故障首版沿用生成记录的 root_channels（目标通道），不私自改成父节点。真实故障边可另作可追溯的边定位附表，但不能混入模型输入。

1. **给定真实事件窗口的定位。**这是条件 RCA，用事件元数据仅圈定评测区域。输出 Top1、Top3（k=min(3,C)）、MRR；多根因才补 root-set recall，并说明真值基数。它回答“已知发生异常，能否找对通道”，不代表自动检测成功。C1 的排名必然平凡，单列，不用于宣称 RCA 提升。
2. **端到端检测→定位。**模型自己预测事件窗和根因。先在独立源验证固定阈值和事件匹配规则，再用于全部方法。事件一对一匹配，未检测事件的联合成功记 0，错误报警另报；指标为全部真实事件中检测且 root 正确的比例，外加事件检测 precision/recall、正常 case 假根因报警率。
3. **时间定位。**有确定注入区间时报告根因通道+时间结果；不把传播尾巴强制当持续注入。已有 root_window/annotation_intervals 可用，旧一维 labels 仍保持原策略。两个监督语义不同应并存说明。
4. **单根因边界。**原生成器通常每个系统一个故障通道，可有多个事件；这不等于覆盖多根因。未设计多根因独立数据前，不声称解决多故障定位。
5. **可识别性。**若两个候选在允许观测下等价，记录等价解释/后验不确定性。正常孪生与真实方程只供独立 oracle 审计；用 oracle 得到的 RCA 不能列为主模型能力。

原三类 `effect/anomaly_channel/anomaly_time` 持续为 null；不为了 RCA 新增阈值化影响标签。可以使用用户已同意保存的实际根因与注入窗口，它们不是上述待定义标签。

## 6. 首轮设计与实际执行记录

2026-10-25当前：B1/C01/C02/C03均完成，详情以各自不可变配置为准。C08独立分支已在5共享H100实际优化：8臂×3seed，每run固定3遍M源数据，共286,359,552原优化标量，额外正常同量；原TimeRCD与共同own-history创新teacher冻结。当前头13,250参数，正常空状态与根因后验共享检测证据，C1原multi logit精确保留。此为联合读出候选方案小试验，不是完整foundation重新训练；尚无新性能结论。原始首轮建议保留如下，不能覆盖各阶段已确认预算和当前实际状态。

先执行 C01/C03 的三臂共同基座，不机械训练十个 proposal：无图机制头、真父图头、真父图+上下文头。seed=348/349/350，每臂每种子 5M 源观测标量，总 45M，固定终点；使用相同源序列、目标监督、优化与数据顺序。再由独立 baseline B1 判断 TimeRCD 表征是否必要。

新头容量匹配；同 C 的关系槽位 padding 一致以控制 dense FLOPs，实际 FLOPs/吞吐/显存仍测量，不先宣称严格相等。原 37,056,515 参数是否冻结/部分微调分别登记，不能把冻结 backbone 的前向计算忽略。正常孪生、上下文重复前向、对比视图、教师/反事实额外计算单列；“45M 观测曝光”不等于总计算只看过 45M 数。

停止条件：固定预算终点或独立配置中的技术时限；非有限 loss、硬信息泄漏、源/目标重合、权重意外变动先停止该新项目。没有性能收益时不自动无限增步。局部机制改善、正常误报与下游任务分别判读；不设“所有子任务都超过 AUC=.85 才允许学习”的联合门槛，也不把 CE 降当因果学习证据。

训练前保存不可变代码、输入/源池/权重 SHA、图约定、机制 exposure、随机种子、实际优化标量、额外计算与 checkpoint 终点规则。最终冻结后再打开锁定测试；真实 TSB-AD/Table1 若没有真 G，须另定现实可得图协议，不能把生成器真图暗移过去。

# C03v4：在预测器压缩之前读取父子历史

这是独立的来源侧机制实验，不覆盖C01–C03v3，不称完整检测方案或新的SOTA。旧对照发现真父/去父值/错父值的目标VUS几乎相同，不能继续把历史校准的收益归于真实因果关系。需要区分“父信息没有价值”与“当前接口没有利用父信息”。

| Research Insight Card | 内容 |
|---|---|
| Problem | 正常DAG已知，边系数、符号和噪声未知，目标不更新参数。检验共享预测器能否从本系统的父子观测配对推断局部机制；来源验证主指标为共同query单位的正常NLL/MSE，辅助ready AP和真实注入根因的条件Top1。 |
| Evidence | C03v3真父/去父值/错父VUS=41.9726/41.9563/41.9575%，差与交互CI跨0；C03v2换错历史损害预测，却尚未证明关系信息作用。R12 CNP提供成熟的配对上下文条件化方法；R13 ANP全文18页及固定作者核心代码已读，展示均值摘要的欠拟合和查询相关检索的价值。外部回归结果不是我们的因果实验结果。 |
| Failure Mechanism | **待检验解释：**跨系统随机关系先被固定teacher压缩为均值/方差，后置尾部校准只能恢复单通道波动，无法恢复已丢失的父子关系。均值压缩也可能隐藏非线性局部关系。C03v3尚未证明这个解释，负结果也可能来自预算、语料或模型归纳偏置。 |
| Key Insight | 给定正常拓扑后，应让新系统过去的父子输入输出配对参与查询分布的构造，而不是只把teacher残差作为上下文。检索时查询只能含自身过去与允许的父观测。 |
| Novel Mechanism | 共享边编码器读取每条允许边过去的(parent lag-bank, child past, child response)配对；查询使用自身过去与父当前/过去。对历史配对均值或按查询注意力读取，再按DAG聚合。训练跨系统共享权重，测试只前向。先检验可用性；注意力、CNP和父条件预测本身均不是新颖性。 |
| Closest Prior Work | R12 CNP、R13 ANP的条件集合回归；R1/R2局部因果分布；R5受限概率预测。区别是已知图、跨图共享、目标无梯度、源配对机制对照与真实注入根因审计。当前没有latent分布/KL、因果发现或反事实识别，不冒称完整ANP复现。 |
| Falsifiable Prediction | 若压缩前关系确实有用，真父上下文应在共同单位NLL/MSE上优于同入度错父和去父值；换错系统上下文应损害该优势。若真图与控制相同，则该接口仍未建立关系收益。若注意力不胜均值，删去“查询检索必要”的claim，保留较简单方法；正常预测改善若不改善AP/RCA，也不称检测成功。 |
| Minimal Experiment | 5臂×3优化种子：真父无上下文、真父均值上下文、真父查询注意力、去父值注意力、同入度错父注意力。独立源312M训练、123M验证，固定3pass/936updates。全程不读250M基准数组；完成后按系统配对、3种子、各C和正反例判读，再决定有限TimeRCD融合实验。 |

## 输入、预算与控制

输入只有观测序列、valid和正常DAG；固定前256点是**观测上下文，不保证正常**。单通道前缀统计不使用查询或未来。48个历史配对在64:4:256；查询t>=320；自身只用1/2/4/8/16/32/64滞后，父可用0/1/2/4/8/16/32/64。真实lag、系数、噪声、根因、标签和正常孪生不进入预测器API。来源训练用正常分支监督其query，来源观测分支只作冻结评估，root/真实窗口只用于评测。

无上下文与均值臂仍保留查询父值输入。全部臂同参数、同seed初始化、数据次序、批量1、固定终点和全部dense边槽位计算；mean/none有效梯度路径和容量不同，不能说有效容量完全相等。去父值臂保留真实入度，不能称完全无图。错父逐目标保持入度、无自身边，可能有环/真实后代，只是非因果预测控制。

正常训练query每pass2,734,336；每run8,203,008，15run合计123,045,120。完整正常序列输入曝光每run11,931,648，合计178,974,720；来源验证initial/pass1/final各包含正常、错上下文、观测三次预测，另记实际查询、Linear和attention matmul FLOPs。原TimeRCD/teacher不加载、不更新；无异常观测/root监督梯度；0目标梯度。随机G0前向/一次反向另计，不称上述曝光是总计算。

三优化种子共享同一源池，不是独立预训练模型。各seed在同GPU型号跑全部5臂；每卡4GiB cap，有>=6GiB剩余即可共享；不停止他人。每run3h/全阶段8h与固定3pass先到停止；技术非有限、G0或SHA失败停止新增调度，保留已完成和正在执行的本项目结果，不因CE下降自动扩预算。

共同query目标和前缀尺度在图模式间不变，NLL/MSE可直接配对，不再比较单位不同的teacher残差损失。记录raw传感器单位MSE作次级审计。前320点当前没有新模型检测分数；ready AP/RCA是来源局部机制指标，不能移贴到完整TSAD主表。后续融合需保护TimeRCD前320/C1并评全部时间点。

## 判读与后续

优先真父对去父值/错父，随后attention对mean/none、错上下文、正常预测到异常AP/RCA的转化、前缀污染及各C。报告系统配对区间和全部正反例，优化种子不能当独立系统。局部、可复现的机制信号可获得小规模融合资格，不要求所有系统达到任意固定AUC；但本轮固定预算无效就停止当前原型，不无限加步。

来源成立后，另立revision接入共同自训练TimeRCD，比较原版、等容量自通道修正、真图修正和错图修正；检测与定位读出分离。不提前读目标/锁定来选head、seed、学习率。源机制不成立则修正解释或转C04精确机制保持/破坏配对，不据此否定整个因果方向。

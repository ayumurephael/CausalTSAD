# C04l：学习可迁移的正常机制表达，并保留关系破坏监督

这是有限学习原型，不是最终foundation模型。原25亿训练数据、TimeRCD权重和250M基准均不改；本阶段完全不读取250M数组。

## 训练与信息边界

已有来源80系统：32train、16calibration、32source_validation，原manifest SHA为6708dc4cbbcbafa37209ba12fe650efc8b50a1a4ad70504bcf316dd6e8f69091。训练只读32train的前4视图（2正常/2完整单通道多重集精确匹配的关系破坏），不使用真实系数/lag/noise；root只供评测，不进入训练损失或模型。

每个模型128步，每步一系统四视图完整1024点；每32系统遍历随机一次，合计4遍。每模型7,340,032输入观测标量，12run总88,080,384。这里同时计入正常和含异常视图，不能再叫“额外正常免费”；唯一数组数与重复曝光不同。奇数步给所有视图加相同观测背景：幅度U[0,4]×共同前缀MAD、周期U[.5,1.25]T，固定step种子；偶数步原样。完整单通道类别多重集每步核验。它是声明的合法观测背景，不是新effect标签。

损失：两个正常视图的Gaussian近似NLL＋0.25×四视图关系BCE。normal_only/frozen_basis的检测证据detach，BCE只更新温度/bias；normal_only的基函数只接收NLL。normal_relation和wrong_graph_relation的基函数另接收BCE。无root监督，因此不能将任何RCA变化归因为root loss。仅温度/bias训练的臂是容量学习消融，不能说有效可训练参数相同；其它三臂参数量相同。名义前向槽位相同，frozen/normal-only与joint反传FLOPs不同，实测时间/峰值显存和分解次数另报。

Adam lr3e-4，梯度范数上限5，float64、TF32关闭。4A100＋6H100按实际显存>=5GiB共享；每worker allocator上限4GiB；12run排队，不停他人。阶段最多6小时与128步先到；错误保留日志和曝光、停止该节点本阶段新调度，后续接手时阻止另一节点新增。不给失败run另加步或无界换lr。

## 固定终点评估和推进规则

每run固定final后评16来源校准系统的两个正常视图×原样/平滑两背景；32来源验证系统评原样、原平滑周期.75T、留出周期1.5T，以及三种图。阈值只从16校准系统两正常视图的两背景得99%分位数；不使用来源验证或目标正常拟合。原样、平滑、留出周期共享一个阈值。8视图中的额外物理/测量故障只评测、不反传。

校准/验证完整前向每run35,782,656输入标量，12run429,391,872；3轮ridge次数和实际CUDA时间另计。原32train四视图已重复，不能冒称新独立系统；3seed在系统内聚合后bootstrap。技术随机数据预检前向37,600/反向4,800每节点另计，不算正式训练。

G0：自身当前/未来盲、非父当前不影响正常均值、图值共同置换等变、闭式解/梯度/有限值/C20均须过，不放宽。模型只接受X/G，不接受row/标签/根因；源码和plan/输入/初末权重SHA固定。

完成后先核验曝光与所有结果，再看normal_relation相对normal_only在各背景的AP/RCA配对和FPR。某一预声明局部条件AP平均提升>=.01、系统配对95%下限>=-.01、3seed至少2个同向，且原样AP不灾难性下降(低于-.05)时，可获一次固定目标迁移资格；可靠置信区间明确为正也可支持更小提升。它只是有限后续实验资格，不是显著成功或SOTA门槛。RCA局部可靠改善也可独立取得定位后续资格，不能替代检测。纯NLL变好、FPR下降但AP掉、真/空图相同均不构成因果检测成功。

若固定128步失败，停当前原型并分析表达/训练分布，而不是无限续训；不否定全部可学习正常机制方向。目标开发、验证和锁定本阶段都不开，下一次迁移配置由来源证据冻结后另存。

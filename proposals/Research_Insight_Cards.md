## C01 — 共享父条件创新：判断“是否违背关系”，而非只判断数值异常

**实测更新2026-10-25。**12组训练/100系统评测与12组冻结共同logit对照完成。共同logit下VUS-PR .43342→.43462，AP .47710→.47717，区间跨0且FPR增；真图不稳定优于空/错图。原概率小涨不能作为已学会因果关系的证据；当前原型不扩预算，保留完整正反结果。


| 字段 | 内容 |
|---|---|
| **Problem** | 新系统参数未知，仅有正常 DAG；TimeRCD 原检测头按通道平均 logits，并未显式监督每条正常条件机制。希望改善关系破坏型异常的 VUS-PR/AP，同时输出通道创新供 RCA。 |
| **Evidence** | **事实：**R1/R2 已验证父条件建模的可行性；R2 同时显示条件估计差时可比 joint VAE 更差。代码核查确认原 TimeRCD 有重构/时间分类头，没有父条件概率目标。**推测：**共享的正常机制头可让已学到的时序表征获得更明确的关系监督。 |
| **Failure Mechanism** | 仅看原始数值或混合表征，可能把合法的父驱动变化报成异常，也可能忽略数值常见但与父值不一致的变化；原平均读出还可能混合故障与健康通道证据。需与“只是新增预测头”区别。 |

| **Falsifiable Prediction** | 与同容量无图头相比，真父图在未见系统的机制/边故障上改善，同时不增加正常 FPR；重新连边后收益下降。如果无图、反向图同样好，只能支持额外训练/容量，不能支持方向性因果收益。 |

## C04 — 精确重放的因果对照训练：保留合法变化，暴露真正故障

| 字段 | 内容 |
|---|---|
| **Problem** | 当前源异常主要来自已有注入配方，模型可能依据振幅/持续时间捷径分类，而没有学会机制一致性；合法状态切换也不应都当故障。 |
| **Evidence** | **事实：**R7 已提出因果保持/破坏增强；我们的源记录保留正常分支和完整重放参数。基准留出轨包含合法波动/切换与不同故障。**推测：**精确、难度匹配的对照可比启发式扰动提供更可靠的关系监督。 |
| **Failure Mechanism** | 仅给父/子加不同幅度噪声，正负样本可能只靠幅度区分；把任何驱动变化都作为正常也会漏掉危险外生故障。“沿因果传播”不自动等于正常。 |
| **Key Insight** | 源 SCM 是构建可审计学习任务的工具；标签取决于定义好的合法运行范围与故障操作，而不是看图有没有变。 |
| **Novel Mechanism** | 新建独立源训练池，同一正常系统与随机数下生成：合法运行变化、物理状态故障并传播、只改测量、机制/边故障。合法变化必须限定在源协议定义范围。用重放验证干预位置，按边际幅度、时长和标签先验匹配；增加配对排序/对比损失，同时保留旧检测任务。参数只用于源生成/监督，模型最终只见 X,G。 |
| **Closest Prior Work** | R7 CAROTS CPA/CDA 已高度接近，不能把因果增强作为新颖性。可发展的增量是已知 SCM 精确重放、合法/危险干预分离、跨图零样本、根因真值和边际匹配的反捷径证据。R6 支持合成过程与现实真图的区分。 |
| **Falsifiable Prediction** | 对比普通异常增广，关系错配但幅度匹配的独立源样本上提升更大，合法驱动/状态变化 FPR 不升；若只在强尖峰上提升，不能声称学到因果一致性。 |
| **Minimal Experiment** | 先审计每类 100 个独立源配对的重放与标签，再做普通增强/重放因果增强两臂，3 种子×5M。原观测曝光相等；额外正常孪生与重放前向单列，控制组用同数量普通增强。机制族留出，绝不复制基准开发/验证/锁定数组训练。 |

## C05 — 测量故障与状态故障分离：防止把无辜的子节点判成根因

**实测边界。**6冻结模型×123源M系统的测量隔离：保持根观测相同、非根观测完全normal后，65个有子节点系统的child score平均变化+.01297，95%CI[-.00700,.05416]；35正/30负，超阈值增加仅1系统/1seed。未建立普遍子节点误报，也未证明测量/状态竞争头的收益。保留局部机制和完整潜状态方向，不扩大错误的普遍性claim。

| 字段 | 内容 |
|---|---|
| **Problem** | A→B 时，A 的读数坏了、但真实 A/B 仍正常，与 A 的物理状态故障并影响 B，是两种不同机制。需同时改善测量故障 TSAD 和 RCA。 |
| **Evidence** | **事实：**原生成器明确区分传播与干净传播后替换根通道；R1 测量/干预类型不同；R8 承认外生干预不能覆盖所有攻击。**推测：**单一观测父条件残差在测量错误下会产生错误的下游归因。 |
| **Failure Mechanism** | 以坏传感器 A 的观测预测 B，会使真实正常的 B 看起来不符合机制；根因分数可能从 A 扩散到 B。反过来，若一律修正父值，又可能抹掉真实传播故障。 |
| **Key Insight** | 检测器需要同时推断“系统状态”和“传感器是否可信”，而不是将每个观测都当真实状态。 |
| **Novel Mechanism** | 在 C01 上引入潜在状态 z 与观测通道 x 的两层模型：z 按正常 G 传播，x 由 z 和可能的测量故障产生；根因后验同时包含 measurement/state/mechanism 解释。源 fault 类型可监督，目标不得输入。先做小候选集合、共享参数、可拒判输出，后代仅用于后验解释，不能倒灌进父条件预测器。 |
| **Closest Prior Work** | R1 测量异常、R3 外生归因、R8 创新定位。差异在显式处理观测错误与真实传播的竞争解释及跨系统共享，而不是声称首个潜状态因果模型。 |
| **Falsifiable Prediction** | 保持 A 的观测扰动相同，一组重生成后代、一组后代保持正常，模型应给出不同传播解释，但两者都定位 A。若必须知道故障类型才行，或只偏好上游节点，方案不成立。 |
| **Minimal Experiment** | 在独立源池构建上述配对，比较普通父条件头与双层头，3 种子×5M；参数匹配控制用同大小无类型潜变量头。单列下游误定位率和 Top1，而不新增 effect 标签。异常幅度/根节点深度匹配。 |

## C06 — 时间传播的根因后验：定位首次机制破坏，不追随最大症状

| 字段 | 内容 |
|---|---|
| **Problem** | 故障可能发生在任意深度，症状经过不同滞后到达后代；全事件平均或最大值可能偏向晚出现的大症状。希望提高带时间信息的 RCA 与检测延迟。 |
| **Evidence** | **事实：**源事件有注入时间与通道；图包含有向路径；R1 上游回传未直接建模故障时间，R8 已提供时间定位。**推测：**传播时间的一致性可消歧多个高分节点。 |
| **Failure Mechanism** | 把子节点症状累计给所有祖先会偏好高出度/早层节点；只选最大残差会偏好强下游响应，二者都不等价于找到源头。 |
| **Key Insight** | 合理故障源应同时解释“哪里先不正常”和“随后哪些观测按正常动力学出现”，而非仅因是祖先就得高分。 |
| **Novel Mechanism** | 共享事件头估计 p(root=i,onset=t∣innovations,X,G)，结合 C02 的预测延迟分布做有限时域消息传递；包含独立故障/无法解释分量，允许非根节点起故障。无真实 lag 主输入、无基准真事件窗作为端到端输入。源 onset 仅作目标，拓扑编号与出度不能直接决定 root。 |
| **Closest Prior Work** | R1 PageRank 风格归因，R8 外生时刻定位，R3 对已选目标的噪声贡献。可检验增量是跨系统的传播时序联合解释与测量/状态竞争，不能声称首次时间 RCA。 |
| **Falsifiable Prediction** | 当故障源幅度较小、子症状较大时，真实传播时序优于时间打乱/反向图；若收益只来自偏好早时间或高出度，匹配控制应消除收益。 |
| **Minimal Experiment** | 冻结 C01/C05 的创新，先训练等容量时序头与图时序头，3 种子×5M；在源验证按根深度、路径长度、子/根幅度比分层。短故障/持续故障分别看；没有可靠 onset 真值的样本不硬构造真值。 |

## C07 — 学习机制上的反事实修复：寻找最能解释整次事件的故障源

| 字段 | 内容 |
|---|---|
| **Problem** | 若多个通道都异常，仅依据各自创新不足以确认根因。希望通过“修复哪里能解释这次异常”来改进 RCA，并作为检测辅助证据。 |
| **Evidence** | **事实：**R3 给出基于 FCM 的噪声随机化/Shapley；R5 中位数输入替换并非沿 SCM 的干预。**推测：**可靠学习机制下的修复一致性有助于选择源头，但图本身不足以保证可靠。 |
| **Failure Mechanism** | 把某通道输入设零/中位数，保持后代观测不变，只能反映模型敏感性；一个重要预测特征并不一定是故障源。错误条件模型的反事实也可能自信地误定位。 |
| **Key Insight** | 根因解释应接受机制约束：只修复候选故障机制/外生项，再向后生成其后果，检查是否能同时解释观测与正常行为。 |
| **Novel Mechanism** | 先由 C01/C03 推断机制和噪声后验；对每候选根因做 abduction→限定故障部件的修复→按 G 传播预测，对未修复部分保留后验约束；比较事件解释似然/修复代价。测量故障只修复观测层，状态故障才传播。用不确定性积分，模型不确定时输出拒判。可以后续蒸馏成一次前向头，但教师计算单列。 |
| **Closest Prior Work** | R3 是核心先例；R8 外生变量提供接口；R5 是敏感性对照。我们的机会是跨系统学习与混合故障、显式比较真实故障注入定位和贡献归因，不把 Shapley 改名作新方法。 |
| **Falsifiable Prediction** | 在源 SCM 可审计样本中，学习反事实的修复排序应接近真实生成器 oracle，优于遮蔽；换错图/错机制后应退化。若真实 oracle 也无法唯一定位，应报告不可识别等价候选，不强制说模型错。 |
| **Minimal Experiment** | **先不训练新检测器**：用小规模独立源系统比较 oracle 重放、学习机制、普通遮蔽三者的 Top1/MRR及修复预测误差。只有学习机制已有独立校准/预测证据才做 3 种子×5M 蒸馏；若不具备该条件则保留研究方向、暂停此原型。 |

## C08 — 统一的“无故障/故障源”概率：让 RCA 监督约束 TSAD 汇总

**实测更新2026-10-25。**v1已完成24组，源监督可提高条件RCA，但目标M的dag_joint AP=.47348低于B0=.47940、FPR增。发现原`logmeanexp(root logits)=mean+KL(U||p_root)`把“更确定是哪一个根因”当额外“存在故障”证据。12冻结控制中去KL优于常量/错时序控制；重新训练mean读出使AP=.47914。mean+PCGrad AP=.48017、VUS=.41615，相对B0差值AP+.00077/VUS+.00064、区间均跨0，FPR+.000188。只支持修复原型退化，不宣称稳定总体提升。PCGrad是成熟方法；根因监督与定位置信度分离的接口可保留，不能将其称首次发现因果后验。

| 字段 | 内容 |
|---|---|
| **Problem** | 原检测头没有根因目标；新增通道分数若简单 max，会随 C 变大而增加正常误报，平均又可能稀释单故障。需要同时检测、定位，并在正常样本上拒绝硬选根因。 |
| **Evidence** | **事实：**原 labels 为时间一维、已有源 root 真值；R2 的已知异常变量对照显示聚合有影响，R4 top-k、R7 分数相加并非所有集都好。**推测：**源根因监督可帮助学出更合理的事件汇总，但也可能只帮助 RCA。 |
| **Failure Mechanism** | 先随意汇总检测再附加 root 排名，两者可能互相矛盾；在正常数据上永远输出一个 Top1 会制造“必有故障”的错觉；sum/max 也可把相关症状重复计数。 |
| **Key Insight** | 把“是否故障”和“从哪里开始”做成一个含正常状态的后验，再分别评价两个能力。 |
| **Novel Mechanism** | 以局部创新与有向图解释输出 p_t(∅) 及 p_t(root=i,state=m)，m 区分当前注入/故障持续解释，S_t=1−p_t(∅)，RCA 对状态边缘化后排名。保留原一维检测损失，仅在已知源注入区间监督 active/onset；传播持续状态作为潜变量，不新造逐通道影响标签，也不强迫每个旧标签异常点都有正在注入的根因。单根因与多事件不偷换为多根因已验证。 |
| **Closest Prior Work** | R1/R8 根因分数、R2 的通道汇总、R9 的监督共享GNN及R10的误差均值/节点排名都是先例。差异是跨 C 的含空状态联合校准、源 RCA 目标与原检测/尾部标签兼容；仅加分类头的提升可能是额外监督而非因果。 |
| **Falsifiable Prediction** | 固定相同创新，图后验优于均值/max/LSE，且在高 C 正常样本 FPR 不增；加入 root 目标比同容量仅检测头提高 RCA，若 TSAD 无增益则不能宣称“RCA 提升了检测”。 |
| **Minimal Experiment** | 实际v1固定同一个C01无图创新teacher，8臂×3优化seed：local/dag×有无root损失、错图、base校准、graph-prior、固定错root。每run3遍M源数据=11,931,648原观测，额外正常相同；24run原286,359,552。第一遍源学习曲线与最终第3遍预定，目标仅评估固定final。C1原logit精确保留，不参与优化。参数/Linear FLOPs名义相同，mask导致有效信息和容量不同须说明。源root窗口只作目标，传播尾部不伪造active根因。 |

## C09 — 因果条件尾概率：区分真正机制偏离与正常高噪声

**实测更新。**12组密度/融合完整训练与100development完成。条件pinball=.09770 vs边际=.10711，错误条件显著变差，但M AP=.47867 vsB0=.47940，VUS=.41629 vs.41551，差区间跨0且FPR增。保留正常条件分布部件，不将改善校准称改善目标TSAD或RCA。

| 字段 | 内容 |
|---|---|
| **Problem** | 重尾、异方差和合法波动会使相同残差幅度在不同系统含义不同；低密度也不一定意味着低概率事件。目标是正常波动时 FPR 与各机制上的稳健检测。 |
| **Evidence** | **事实：**R3 将异常度定义为尾事件概率而非单纯似然；R2 的密度估计选择显著影响性能；R4 用 MAD，R8 使用 Gaussian 独立约束，而我们留出轨有非 Gaussian/变方差。**推测：**条件尾概率比全局标准化残差更适合跨系统。 |
| **Failure Mechanism** | 简单除以全局 σ 会让正常高波动窗口误报，也会让持续故障膨胀尺度而掩盖自身；仅优化 NLL 可通过增大预测方差降低损失，却没有区分故障。 |
| **Key Insight** | 需判断“在当前正常条件机制下，这种偏离有多罕见”，并防止查询异常参与估计自己的容忍度。 |
| **Novel Mechanism** | C01 的共享概率头增加条件分位数/可采样分布，使用源正常数据学习残差的条件尾分布；上下文估计尺度与查询隔离，输出校准的惊异度，再与故障后验融合。不把有限经验校准宣称为非交换时序下严格 conformal 保证。真实噪声参数不输入。 |
| **Closest Prior Work** | R3 信息论 outlier score，R2 CVAE/KDE，R4 稳健残差，R8 标准化外生变量。新增研究问题是跨系统无更新、合法波动和污染上下文下的因果条件校准；尾分数本身已有。 |
| **Falsifiable Prediction** | 在相同 DAG/故障幅度、噪声不同的独立系统上，正常分数更可比；关系异常 AP 不因“放大不确定性”而消失。若仅 FPR 降、检测召回也等幅降，不能称机制区分有效。 |
| **Minimal Experiment** | 同一条件特征比较 Gaussian/MAD/分位数尾头，容量匹配、3 种子×5M；独立源验证覆盖率与尾概率，再在开发集分噪声族、合法切换和故障类型报告，不用目标纯正常真值重新拟合阈值。 |

## C10 — 因果角色组合与通道置换等变：从固定系统模型到跨图基础模型

| 字段 | 内容 |
|---|---|
| **Problem** | 许多因果 AD/RCA 方法为每个固定变量建立独立参数，无法直接处理新通道数、重编号和新图。我们需要可跨系统迁移的 TimeRCD，而不是每个生成样本训练一个图模型。 |
| **Evidence** | **事实：**R5 每目标独立块、R8 网络维度绑定 num_vars；R6 讨论共享结构；我们的通道已置换，且有 C1/8/12/16/20。**推测：**共享因果角色计算与组合训练可更有效利用这些变化。 |
| **Failure Mechanism** | 若网络利用节点编号、出入度或常见图形状猜测故障源，可能在相同生成配方上得高分，但对新图/新根位置失效；“知道 DAG”并不自动获得组合泛化。 |
| **Key Insight** | 模型应学习可复用的局部因果计算规则，而不是记住某个通道或一张图。 |
| **Novel Mechanism** | 因果分支使用共享通道编码、对父集合顺序等变的聚合、同一物理时间的位置编码与方向类型，源训练做全通道重编号、图 motif/故障根深度平衡。图结构输入与值分开；原 TimeRCD 分支保留作能力参照，整体融合也必须检验重编号稳健性，不能只检查新分支。 |
| **Closest Prior Work** | R6 共享 CDNN 是先例，R1/R2 局部机制也是先例。共享/等变本身是成熟思想；可检验差异是与自训练 TimeRCD 结合后，在已知图零样本 TSAD+RCA 上跨图组合泛化，而不是仅把 GNN 放进模型。 |
| **Falsifiable Prediction** | 同一观测和 G 同步重编号后，恢复原顺序的因果输出应数值等价；只给 G 不给值应接近先验基线；在新 motif、根深度和通道数上真图仍优于保持度数的错图。若收益仅来自图形状预测 root，因果学习解释不成立。 |
| **Minimal Experiment** | 不新增训练先做等变和图-only审计；再用共同源曝光比较普通图头与角色共享/组合训练头，3 种子×5M。图形状/机制家族按系统留出；不把基准 locked 当 motif 调参集。新 C 超出已有 20 的实验需要独立源诊断，不冒充现有 250M 的测试覆盖。 |

## 如何形成一条可执行路线

| 顺序 | 可整合的方案 | 先解决什么 | 继续/修改的依据 |
|---|---|---|---|
| 1 | C01、C03，C10 的输入纪律 | 给定 G 能否真正改善跨系统条件机制 | 真父图对等容量无图/错图有独立源证据；不是只有 CE 下降 |
| 2 | C04，按错误类型加入 C02/C09 | 正常机制变化与故障能否分开 | 源配对关系反证、正常 FPR、各故障 AP；不由单个整体阈值一票否决 |
| 3 | C05、C08；必要时 C06 | 能否定位初始故障而非最大症状 | oracle-window 与端到端分别报，测量/状态/边故障和负例齐全 |
| 4 | C07 | 学习机制能否支持可信修复解释 | 先验证机制，再看反事实；不具备条件时保留方向而不硬推原型 |
| 5 | 冻结最终完整方案 | 是否提升新系统测试与现实迁移 | 一次锁定 150M 评估；真实数据无真图时另行定义图获取协议 |

这一顺序不是要求逐个训练十个模型。一个共同基座和少量有针对性的分支对照更容易回答“DAG 带来了什么”。若成熟机制已经有效，优先保留简单方案；若效果来自额外监督、额外计算或普通预测能力，应如实命名其贡献。
